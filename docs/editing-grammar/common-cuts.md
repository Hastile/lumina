# 공통 컷 문법 — 쇼츠 / 롱폼

## 기본 단위는 자막 한 장이 아니라 시청자가 이해해야 하는 한 가지

샷을 배정하기 전에 내레이션을 **설명 대상 + 주장/행동 + 필요한 증거**로 묶는다. 한 문장에 대상이 두 개면 나눌 수 있고, 여러 자막이 같은 행동을 설명하면 한 샷을 유지할 수 있다. 자막 교체·문장 마침표·음악 박자는 자동 컷 명령이 아니다.

| 질문 | 기본 선택 | 예외 / 주의 |
|---|---|---|
| 보여줄 대상·사건·논점이 바뀌는가? | 새 컷 또는 같은 화면 안 대상 추가 | 비교가 목적이면 이전 대상을 남기는 편이 낫다 |
| 현재 샷이 다음 구절도 충분히 설명하는가? | 유지 | 대상이 가려지거나 읽을 증거가 작으면 리프레임 |
| 동작이 준비→실행→결과로 이어지는가? | 결과를 인지할 때까지 유지 | 의도적인 시점 전환으로 행동을 더 분명히 보여줄 수 있을 때만 컷 |
| 말은 끝났지만 시청자가 자료를 읽는 중인가? | 읽을 시간을 확보 | 설명과 별개인 자료를 길게 붙잡지 않는다 |
| 같은 대상을 더 자세히 보아야 하는가? | 부분 확대·강조 또는 설명용 인서트 | 의미 없는 전후 줌 반복 금지 |
| 화면을 바꿀 이유가 단지 시간이 지났기 때문인가? | 유지하거나 더 적합한 소스를 찾음 | 반복 동작·정지 화면의 지루함도 실제로 확인해야 한다 |

**새 컷·레이어 등장·텍스트 강조·카메라 이동은 서로 다른 수단이다.** 같은 논점에서 키워드가 추가된다고 전체 화면을 갈아엎지 않는다. 이시고리의 세 가지 정체성 누적, 레제의 STP 누적은 이 원칙의 근거다.

비교 정보를 유지한다는 것이 배경 영상까지 고정하라는 뜻은 아니다. 이시고리 183.8초와 185.5초의 Lumina 합성 표본에서는 첫 문구가 남은 채 행동 영상이 바뀌고 두 번째 문구가 추가된다. **기억할 정보는 유지하고, 현재 주장을 입증하는 영상은 갱신**할 수 있다. 배경 컷과 새 항목 등장으로 시선이 동시에 분산되면 둘의 시점을 어긋나게 하거나 배경의 대비를 낮춘다. 이 조정은 개선안이며 원본의 청감·리듬 검증 결과가 아니다.

## 의미 경계와 공개 시점

- 수식어와 대상, 목적어와 동사, 행동과 결과를 무의미하게 분리하지 않는다. `들고 / 온`, `해결하지 / 못했던`은 자막에서도 컷 계획에서도 경고 신호다.
- 새 주어가 나오면 그 주어를 보여준다. 비교에서는 이전 주어와 새 주어를 함께 놓는 방법도 검토한다.
- 원인→결과, 질문→답, 기대→반전의 공개 시점을 지킨다. 정답을 숨긴 도입에서 얼굴·이름·결과 화면을 미리 노출하지 않는다.
- 특정 사건을 말할 때는 그 사건의 실제 소스를 쓴다. 같은 인물의 다른 전투를 해당 사건처럼 제시하지 않는다. 비유·모티브 비교는 오해하지 않도록 이름·출처·연결 설명을 붙인다.
- 도입에서 짧은 컷을 쓰더라도 하나의 궁금증을 만들어야 한다. 빠른 컷의 개수가 흥미를 보장하지 않는다.

## 소스 선택 순서

1. 주장에 직접 대응하는 행동·표정·디자인·문서 증거.
2. 해당 대상을 정확히 보여주는 중립 샷이나 정지 이미지.
3. 설명을 돕는 비교 자료·도식. 비유인지 사실의 증거인지 구분.
4. 장식용 영상은 맥락을 해치지 않는 보조로만 사용.

소스 DB 설명·파일명은 후보를 찾는 단서다. 실제 프레임과 구간을 확인한다. 화면에 글자가 이미 많거나 얼굴이 잘리는 소스를 억지로 쓰지 않는다. 좋은 원본 동작을 먼저 선택하고 정지 샷에 일괄 줌을 붙여 활기를 흉내 내지 않는다.

## 중복 장면 재활용은 매우 신중하게

**사용자 확정 지침 (2026-10-31): 중복 장면은 정말 신중하게 재활용한다. 초안에서 같은 장면으로 빈 구간을 때운 듯한 편집이 많이 보였다는 피드백이다.** 쇼츠·롱폼 모두 적용하며 초안도 예외가 아니다.

- 이미 사용한 장면을 편한 기본 소스로 반복 배치하지 않는다. 같은 인물이 나온다는 이유나 길이가 맞는다는 이유만으로 재사용하지 않는다.
- 재사용할 때는 **앞선 사용 위치·당시 역할·이번에 새로 보여줄 근거·다른 소스보다 이 장면이 필요한 이유**를 컷 계획에 적는다. 이유를 구체적으로 설명할 수 없으면 다른 소스를 찾거나 구성을 바꾼다.
- 회상·전후 비교·복선 회수·같은 사건의 다른 세부를 검증하는 경우처럼, 다시 보여주는 행위 자체가 설명에 기여할 때만 검토한다. '강조용', '분위기용', '소스 부족'이라는 이름만 붙여 반복을 정당화하지 않는다.
- 크롭·줌·좌우 반전·속도 변경·몇 프레임의 in/out 변경만으로 같은 장면이 새 근거가 되지는 않는다. 같은 파일의 다른 구간도 실질적으로 같은 행동·구도면 중복 후보로 본다. 반대로 같은 파일 안의 별개 사건을 파일명만으로 중복 판정하지 않는다.
- 소스가 부족하면 다른 실제 장면·정지 이미지·비교 자료·도식을 검토하거나, 설명에 맞는 샷을 자연스럽게 유지한다. 적합한 자료를 못 찾은 구간은 미해결로 남긴다. 관련 없는 영상이나 반복 샷으로 채워 완료 처리하지 않는다.
- 검수 때는 반복 사용한 소스 구간을 모아 최초 사용과 재사용을 앞뒤 내레이션까지 연속해서 비교한다. 새 정보가 있는지, 장면이 다시 시작되는 느낌이나 때운 느낌이 나는지 확인하고 불필요한 반복을 교체한다. 반복 횟수·간격에 기계적인 허용 기준을 두지 않는다.

## 길이와 속도

- 고정 초수나 '자막 N개당 1컷'을 목표로 삼지 않는다. 네 레퍼런스의 미디어 클립 중앙값은 2.77~4.00초지만, 겹친 이미지·오버레이가 포함된 **클립 인스턴스** 통계라 샷 길이 규칙으로 사용할 수 없다.
- 짧은 컷이 연달아 나오면 각각 새 정보가 있는지 확인한다. 이름 카드·누적 등장·의도적인 리액션은 설명 샷과 다르게 평가한다.
- 긴 컷은 하나의 행동·비교·자료 읽기가 이어지면 허용한다. 길이만으로 부족한 리듬이라고 판정하지 않는다.
- 속도는 100%부터 검토한다. 부족한 길이는 소스 범위·샷 설계를 먼저 바꾼다. 속도 조절은 동작이 자연스럽고 목적이 있을 때만 사용한다. 원본에 잦은 속도 변경이 있어도 그 빈도를 목표로 삼지 않는다.
- 쇼츠의 기존 최소 길이·마커 관련 사용자 조건은 쇼츠에서 유지한다. 롱폼에 숫자만 복사하지 않는다.

## 화면 구성과 움직임

- 얼굴/설명 부위/읽을 문구가 자막과 겹치지 않게 배치한다. 크기는 채우기보다 알아보기 쉬운 정도로 정한다.
- 비교는 같은 축으로 정렬한다. 키 비교는 발 기준선과 표시 수치를, 디자인 비교는 해당 부위와 비슷한 확대율을 사용한다. 그림 포즈만으로 실제 신체 비율을 확정하지 않는다.
- 기본 프레이밍은 고정한다. 카메라 이동에는 추적·공개·관찰 부위 안내 중 하나의 목적이 있어야 한다. 대상이 멈추면 추적도 멈춘다.
- 두 인물을 비교할 때마다 컷을 왕복하기보다 한 화면에 남겨 비교 비용을 줄인다. 정보가 과밀하면 비교 항목을 나눠 순차 제시한다.
- 비교 축에 맞는 크기를 쓴다. 신장 비교에는 발 기준선이 필요하지만 헤어스타일 비교에는 머리의 크기·각도가 우선이다. 전신 키를 맞추는 규칙을 모든 비교에 적용하지 않는다. 이시고리 201초 표본의 전신 3인 구성은 인물 소개에 유리하나 머리 형태 비교를 개선하려면 헤어 인서트가 더 직접적이다.
- 이미 소스 안에 화살표·빛·동작 강조가 있으면 새 강조를 자동으로 겹치지 않는다. 호시노 101초 표본에는 약실 부근의 노란 원형 강조가 보인다. 먼저 기존 강조의 역할을 확인하고, 자막이 그 부위를 가리면 자막 위치부터 검토한다.

## 증거를 보이게 하는 연출과 보존할 구도

[두공탁 두 편의 화면 근거](references/dugong-frieren-opening.md)를 바탕으로 다음을 공통 적용 후보로 삼는다.

- 작은 세부가 근거라면 **전체 맥락→관찰 위치 지정→확대→읽기 유지** 순서를 검토한다. 확대되는 소스와 해설 자막은 분리한다.
- 여백·인물 사이 거리·화면비가 근거라면 전체 구도를 보호한다. 자동 채우기 크롭과 인물 중심 줌으로 증거를 없애지 않는다. 쇼츠에서도 전체 구도 인서트를 선택할 수 있다.
- 주석은 필요한 순간에만 보이고 퇴장시킨다. 가이드로 시선을 잡은 후 원래 밝기와 깨끗한 화면을 회복한다. 원작에 이미 충분한 안내가 있으면 추가 강조를 생략한다.
- 설명용 합성·변형은 원작과 구분한다. 기준 화면에서 변수를 하나씩 바꾸고, 원본을 다시 제시한다. 가공 결과를 원작의 사실로 오해하게 하지 않는다.
- 애니 원작의 카메라 이동·작화와 채널 편집의 개입을 구별한다. 좋은 소스 구간을 온전히 고르는 것도 편집이다.

## 읽을 정보와 스쳐 보여줄 정보

카드마다 `역할 = 읽기 / 회상 / 분위기`를 먼저 정한다. 읽기 카드는 처음 보는 내용을 정상 속도에서 이해할 수 있어야 한다. 회상 카드는 이미 설명한 항목을 다시 불러오는 용도이며, 짧아도 되는 대신 새 논거를 숨겨 넣지 않는다. 분위기 카드는 문장 전체를 읽어야 다음 내용을 이해하는 구조로 쓰지 않는다.

덴지 258.5/259.5/260.5초의 Lumina 표본은 큰 SWOT 약어와 네 개의 문장을 가진 카드다. 정지 화면에서 글자가 선명하다는 사실은 약 1초에 네 문장을 읽을 수 있다는 뜻이 아니다. 반대로 짧다는 이유만으로 실패한 컷이라고 확정하지도 않는다. 앞뒤 음성과 역할을 확인한 뒤, 읽기 목적이면 핵심 차이 하나를 남기고 회상 목적이면 이미 설명한 핵심어로 압축한다. **카드의 모든 줄을 읽히려고 영상 전체를 무작정 늘리는 것은 기본 해결책이 아니다.**

## 경계 품질

[컷·프레임 튐 판정과 보정](cut-quality.md)을 적용한다. 대표 이미지나 장면 변화 수치만으로 합격시키지 않는다.

- 원본의 이전/다음 장면이 한두 프레임 섞이지 않게 in/out을 검사한다. 소스 내부 장면 전환도 확인한다.
- 컷 직전/직후, 강조 등장 직후를 프레임 단위로 본다. 흰 플래시·디졸브 잔상·점프를 길이 늘리기나 느린 재생으로 숨기지 않는다.
- 기본은 명확한 컷이다. 전환 효과는 시간·공간·챕터 관계를 설명할 때 사용한다. 특정 Premiere 플러그인의 전환을 재현하는 것 자체가 목표가 아니다.

## 개선안 평가

레퍼런스를 바꿀 때 `기존 방식 → 문제 → 대안 → 검수 결과`를 남긴다. 좋은 변화는 (1) 말하는 대상이 더 빨리 보이고, (2) 비교·자료가 더 쉽게 읽히며, (3) 불필요한 전환이 줄고, (4) 행동과 감정의 흐름이 보존되는 것이다. 컷 수·줌 수·효과음 수 증가를 발전의 지표로 삼지 않는다.
