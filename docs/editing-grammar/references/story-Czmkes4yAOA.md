## 핵심 판단

이 레퍼런스에서 우선 가져올 것은 **예상할 기준을 먼저 주고, 실제 결과를 보여주고, 그 결과 때문에 다음 판단이 바뀌게 하는 구조**다. 통계 화면이 반복돼도 각 화면이 대답하는 질문은 바뀐다. 실험 과정과 유튜브 설명이 따로 진행되지 않고, 설명이 다음 결과를 이해하는 준비가 된다.

`질문 → 선택과 예상 → 실행 증거 → 예상과 실제의 차이 → 해석 → 다음 선택`

이 구조를 캐릭터 해설에 적용할 때는 원작에 없는 위기를 만들지 않는다. 사건의 실제 순서와 해석을 구분하고, 결론에 불리한 장면도 검토한다.

- 그림자는 자료 카드와 배경을 분리하는 용도로 쓴다. 비네트·블러·확대를 모든 컷에 함께 걸지 않는다. 현재 화면의 주도권을 어느 레이어가 갖는지 먼저 정한다.
- 반응용 확대는 웃음의 대상을 읽힌 뒤 밈을 얹고, 다음 논점에서 크기와 레이어를 정리한다. 맥락이 바뀌었는데 밈·효과 꼬리가 남지 않게 확인한다.

## 재시청 가치에 관한 해석

최종 수치를 이미 아는 시청자는 중간의 결정과 회수 구조를 다시 볼 수 있다. 작은 성과를 어떻게 해석하고, 정체를 어떻게 견디며, 새로운 시도를 어떻게 고르는지가 남는다. 특히 초반에 제시한 그래프를 후반에 알아보는 경험과 16분대의 자기 의심 공개는 결말의 놀라움만으로 성립하지 않는다.

사용자의 재방문 이유를 '동기부여가 필요해서'라고 단정하지 않는다. 검증할 가설은 **결과의 놀라움 + 과정을 이해하는 만족 + 다시 시도할 수 있다는 메시지**의 결합이다.

## 우리 영상으로 발전시키는 방법

- 대본의 각 단락에 `시청자가 가진 질문 / 현재 예상 / 화면 증거 / 보고 난 뒤 달라지는 이해`를 적는다. 설명 항목만 바뀌고 질문이 이어지지 않으면 접속을 다시 설계한다.
- 분석 기준 하나를 초반에 간결하게 소개하고, 후반의 실제 장면에서 같은 기준을 회수한다. 그래픽의 모양도 일관되게 유지하되 원본의 손그림 스타일을 복제할 필요는 없다.
- 호시노라면 보호 행동의 나열에서 더 나아가, 보호와 자기희생을 어떤 장면으로 구분할지 질문을 세울 수 있다. 덴지라면 욕망을 나열하기 전에 욕망의 대상이 달라지는 순간을 무엇으로 판단할지 정한다. 이는 대본 제안이지 이번에 원작 근거까지 검증한 결론은 아니다.
- 비교 화면은 수치와 크기를 넘어 **이전 예상과 실제 결과**도 비교할 수 있다. 반전이 사실에 없으면 만들지 않는다.
- 원본의 약점을 보완한다면 세 목표의 달성/미달성을 간헐적으로 짧게 재표시해 후반의 수익 목표가 갑자기 생긴 문제처럼 느껴지지 않게 한다. 상시 HUD는 화면 부담이 있으므로 필요한 전환에서만 검토한다.
- 알고리즘의 의도에 대한 화자의 설명은 영상 속 해석이다. 공개된 관찰과 플랫폼 내부 원리에 대한 추측을 우리 문서에서는 분리한다. 한 사례의 성공을 보편적 성공 공식으로 옮기지 않는다.

## Codex / Claude 실행 메모

컷 계획에 다음 필드를 추가한다. 도구가 화면을 잘 만들었더라도 근거가 없는 관계를 만들어서는 안 된다.

```text
질문:
시청자의 현재 예상:
관찰 가능한 증거:
화면의 역할: 기록 / 설명 / 반응 / 공개 / 회수
이 구간 뒤 달라지는 이해:
앞에서 준비할 것 / 나중에 회수할 것:
소리의 계획과 실제 청취 상태:
```

기존 쇼츠 자막 분할 기준은 변경하지 않는다. 질문–증거–판정과 예상–회수는 쇼츠에도 적용할 수 있지만, 롱폼의 여러 목표·긴 대기 구간을 그대로 축소해 넣지는 않는다.

## 검수 근거와 소리의 한계

- 로컬 완성본에서 정확한 시각으로 추출한 81개 프레임을 직접 확인했다. 추가로 전반 흐름용 30초 간격 시트를 확인했다. 전체 영상을 정상 속도로 연속 시청했다는 뜻은 아니다. `frames-1.jpg`~`frames-7.jpg`에 시각을 표시했다.
- vidIQ 자막(5크레딧)과 영상 분석(25크레딧)을 대조했다. 자동 자막에 숫자·고유명사 오류가 있어 그대로 인용하거나 통계로 집계하지 않았다. 사용자의 제공 로컬 파일은 업로드하지 않았으며 공개 URL로 분석했다.
- 이 세션은 직접 오디오 입력을 지원하지 않는다. vidIQ는 01:03–01:10의 삐 효과음과 위기 구간의 차분해진 내레이션을 보고했으나, 이는 도구의 보고이며 직접 청취로 교차 검증하지 못했다. BGM 곡명, 정확한 음악 컷, 무음 길이, 덕킹 수치 등은 확정하지 않는다.
- 도구의 '촛불이 꺼진다'는 설명은 확인한 표본과 맞지 않아 채택하지 않았다. 도구가 정체기 전략으로 묶은 구독 유도 기획은 자막상 그보다 앞인 3분대에 등장하므로 시간순서를 바로잡았다.
- 음향 적용안: 판정 직전의 정보량을 줄이는 화면에서 소리도 덜어낼지, 실제 기록 영상의 소리를 살릴지, 결과 후 내레이션이 효과음에 가리지 않는지 비교 청취한다. 이번 영상에서 들은 믹스 규칙으로 주장하지 않는다.
