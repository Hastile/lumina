## 구현 원인과 다음 보정 우선순위

1. 문장 끝 검출부터 보강: 전체 텍스트 형태소 분석에서 `달랐는데요`, `했는데요`, `있는데요`의 끝 품사가 MM/EC로 잡혀 종결을 놓친 사례가 있다. 일부는 금지 경계 규칙이 문장 경계보다 우선해 합쳐진다. 요체 종결을 문맥과 함께 판정하고 새 주어를 이전 문장에 붙이지 않아야 한다.
2. 결합 표현 보호 보강: 현재 다음 단어가 VX일 때 주로 보호하지만 `들고 온`, `보게 된`은 VV, `해결하지 못했던`은 MAG로 분석됐다. 품사 한 쌍만으로 보호하면 놓친다.
3. 숫자 목표보다 의미 경계를 우선: 현재 내부 절을 너무 비싸게 평가해 끝까지 병합한 뒤, 전체 길이를 줄이려고 어색한 위치에서 자른다. `-처럼/-하게 + 서술어`, `-라고 + 부르다`, `수량/방향 + 동사`를 보호하고 절 끝을 우선한다.
4. 호시노를 기준으로 기본 호흡 재조정: 현재 중앙값 24자·3.44초는 초기 제안 범위의 상단에 몰린다. 우선 종결·결합 표현을 고친 뒤 길이 비용을 재평가한다. 단순히 길이 상한만 낮추면 어색한 내부 분할이 늘 수 있다.
5. 호시노 한 편에만 맞추지 말고 이시고리·덴지·레제를 보류 검증 자료로 사용한다. 쇼츠 모델과 분할 정책은 계속 별도로 유지한다.
