# 캐디노트 대본·영상 편집 통합 패키지

2026-10-31 · v1.0

기존 대본 지침 5개와 편집 요약, Lumina 최신 실행·컷 지침을 한 Chat 프로젝트용으로 정리했다. 모든 내용을 한 긴 파일에 합치는 대신 **같은 규칙의 주인을 하나로 정하고 작업별 파일을 나눴다.** 원본은 변경하지 않았다.

## 적용 방법

1. `PROJECT_INSTRUCTIONS.md` 본문을 프로젝트 지침 칸에 넣는다.
2. `01_COMMON.md`부터 `06_EXAMPLES_REFERENCE.md`까지 **6개 파일**을 참고 파일로 넣는다. 압축 파일을 받았다면 풀어서 이 파일들을 추가한다.
3. 기존 대본 6개와 예전 편집 패키지의 01~05는 같은 프로젝트의 활성 참고 파일에서 이 6개로 교체한다. 원본 백업 ZIP·SOURCES.json·이 README·변경표는 보관용이며 업로드할 필요 없다.
4. 실제 영상 편집을 할 때 GPT Bridge를 연결하고 04에 따라 도구를 확인한다. 대본 작성·교정만 할 때 Lumina 연결을 먼저 요구하지 않는다.

| 파일 | 단일 담당 역할 |
|---|---|
| PROJECT_INSTRUCTIONS.md | 지침 칸용 상위 판단·작업 분기·확정본 보호 |
| 01_COMMON.md | 채널 방향·근거 등급·공통 문체·수정 권한·자체 검수 |
| 02_SCRIPT.md | 쇼츠/롱폼 구조·마무리·제목·고정댓글·TTS·화면 큐 |
| 03_EDITING.md | 공통 컷·중복 샷·자막·포맷별 스타일·음향·최종 검수 |
| 04_LUMINA_MCP.md | Chat/Bridge/Lumina 실행·내부 음성 정렬·보호·저장 |
| 05_RESEARCH_REFERENCE.md | 전문 조사용 개념·보고서·증거 장부. 필요할 때 적용 |
| 06_EXAMPLES_REFERENCE.md | 문체 예문·대본 샘플·과거 시청자 자료·연출 근거. 규칙이 아닌 참고 |

**한 Chat 프로젝트**는 대본과 편집의 맥락을 함께 관리한다는 뜻이다. 서로 다른 작품의 `.lumina` 파일이나 원고를 하나로 합치지 않는다.

## 이어서 작업할 때 남길 정보

작품/포맷, 핵심 질문, 자료 기준일·스포일러 범위, 확정 원고 버전·잠근 문장, 미낭독 TMI, 실제 음성 테이크, 프로젝트 경로·시퀀스 ID, 큐별 소스 확보 상태, 완료/미해결/다음 작업을 한 작업 메모로 이어간다. 사용자가 전체 제작을 요청하면 승인된 범위를 이어서 수행하고, 대본만 요청하면 대본까지만 한다.

시작 요청 예:

> 01과 02를 기준으로 이 롱폼 원고를 다듬어줘. 확정한 도입은 유지하고, 본문은 실제 시청 순서대로 수정해줘. 화면이 꼭 필요한 근거에는 큐를 붙여줘. 아직 Lumina를 수정하지는 마.

> 확정 원고와 음성으로 이어서 영상 편집해줘. 03과 04를 읽고 열린 프로젝트·시퀀스를 확인해. 기존 자막 문구와 스타일은 유지하고 음성에 재정렬한 뒤, 중복 샷을 엄격히 검토해서 컷을 구성하고 검수·저장해줘.

## 유지보수와 보존

편집 가능한 통합 원본은 `D:/Dev/lumina/docs/content-project/`다. 배포본은 사용자가 지정한 지침 폴더 아래 `통합_프로젝트_2026-10-31/`에 둔다. 통합 문서가 바뀌면 프로젝트에 올린 파일도 교체해야 한다. 자동 동기화된다고 가정하지 않는다.

`MERGE_NOTES.md`에 병합 대응·충돌 해결을 기록한다. `SOURCES.json`은 출처 경로·해시와 통합 파일 해시다. `ORIGINALS_BACKUP.zip`은 통합 당시 원문을 보존한 자료이며 현행 프로젝트 지침으로 중복 업로드하지 않는다. `Caddynote_Unified_Project.zip`에는 지침·참고 6개·README·변경표·출처 목록만 담는다.

`build_support.py`는 최초 실행 시 원문을 백업하고 이후에는 그 백업에서 참고 05/06을 재생성한다. 05의 실제 IP 개념 예시는 `research_ip_examples.json`에서 읽어 해당 개념 아래에 출처와 함께 삽입한다. 예시 수정은 이 원본에 반영하고 다시 빌드한다. 이 보조 파일은 업로드할 필요가 없으며 예시 본문은 05에 포함된다. 공식 설정·제작자 설명과 분석자의 해석, 이용자 연구의 표본 범위를 구분한다. 01~04와 PROJECT_INSTRUCTIONS는 편집한 통합 원본이며 스크립트가 덮어쓰지 않는다. 원문이 바뀌었으면 새 출처를 검토하고 새 버전으로 통합한다.
