## 결정 사항

1. **'구어체' 대 '문어체 유지':** 문체 v2.2의 문맥 판정을 따른다. 전문어·복문·대조·피동·유보를 금칙어처럼 삭제하지 않는다.
2. **진행 멘트 제거 대 롱폼 고정 도입:** 고정 진입 문장은 유지한다. 그 문장에 작업 범위를 덧붙이지 않고 일반 본문 예고는 필요한 경우만 남긴다.
3. **결론 회수 대 전체 요약 금지:** 도입의 답은 본문/피드백 마지막 판정에서 완결하고, 별도 마무리에서 또 전체를 읽지 않는다. 롱폼의 댓글 질문·구독 안내는 유지한다.
4. **자료가 없으면 문장 변경 대 확정본 보호:** 초안은 근거·문장을 재설계할 수 있다. 확정본 편집은 소스 부족을 큐별 미해결로 기록하고 원고를 몰래 지우지 않는다.
5. **출처 전수조사 대 가벼운 수정:** 05의 전체 보고서는 깊은 조사 작업에만 적용한다. 단순 문장 교정마다 24개 범주 전수조사를 시작하지 않는다. 원고의 근거가 부족하면 그 주장에 필요한 확인을 한다.
6. **'새 검색 없이 대본 작성'의 범위:** 리서치는 충분한 증거를 마련하는 목표다. 미확인·시점 변경이 드러났을 때 추가 확인을 금지하는 뜻이 아니다. 부족한 근거를 채워 완료라고 꾸미지 않는다.
7. **성과 표본 대 규칙:** 과거 CTR·조회율·조회수·컷/효과 비율을 현행 상태·인과 증명·제작 할당량으로 쓰지 않는다. 자막 수로 컷 수를 정하지 않는다. 별도로 사용자가 확정한 쇼츠 최소 샷 길이·스타일·음량은 해당 포맷에서 유지한다.
8. **샘플의 사실성:** 작품·인터뷰·반응 사례와 가상 문체 예시는 재검증 없이 다음 대본의 사실 근거가 될 수 없다.
9. **영상에 따라 다른 개입:** 대본 작업은 실제 타임라인 변경을 뜻하지 않는다. 영상 편집 요청은 확정 대본 재작성 권한을 뜻하지 않는다. 전체 제작 요청은 승인된 단계들을 계속 수행한다.
10. **구형 Phrase / 개인 CLI:** 기본을 Lumina 내부 speech 도구로 바꿨다. 구형 외부 Phrase는 도구 부재 시 검토할 대체 경로다. 개인 메모리·셸 명령을 Chat의 상시 기능으로 전제하지 않는다.
11. **자막 재정렬 대 새 트랙 생성:** retime은 기존 문구·ID·스타일 보존, script/transcribe는 새 트랙 생성이다. 새 트랙을 기존 자막 위에 중복 렌더하지 않도록 검수한다. 대본의 문장과 자막 분할을 동일시하지 않는다.
12. **최신 자막 운영:** 대본/기존 자막 정렬은 중간 공백 제거, Enter 분할·Shift+Enter 개행·맨 앞 Backspace 병합, 국소 문장부호/공백 수정 후 정렬 정보 유지, 자동 반영과 파일 저장 구별을 포함했다.
13. **중복 장면:** 2026-10-31 사용자 확정 기준을 공통 컷의 독립 항목으로 올렸다. 초안도 빈 구간을 반복 샷으로 때우지 않는다.
14. **좌표·표본 수치:** 특정 엣지러너 프로젝트의 Y 788/중심 950을 채널 공통값으로 올리지 않았다. 박스 좌상단과 점 텍스트 중심을 구분하고 프로젝트별 합성으로 확인한다.
15. **내레이션 리미터:** 최신 운영 문서의 -4dB/boost 0/look-ahead 7ms/release 100ms를 사용한다. 과거 README의 release 200ms 근사 셸식은 현행 실행에서 제외했다.
