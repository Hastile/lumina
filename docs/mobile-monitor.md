# 휴대폰 읽기 전용 모니터

2026-11-01 설정. 같은 tailnet의 휴대폰에서 Tailscale을 켜고 **http://100.72.70.28:8766/** 에 접속한다. PC와 Lumina가 켜져 있어야 한다.

- 프로그램 합성 이미지와 활성 시퀀스의 V/A 타임라인을 표시한다.
- 약 2초 주기로 상태·프레임 갱신. 휴대폰에서 클립 선택·시점 슬라이더·확대·스크롤 가능.
- 시점 선택은 휴대폰 미리보기만 바꾸며 PC 재생헤드·시퀀스·편집·저장 상태를 바꾸지 않는다.
- PC 따라가기는 마지막 엔진 동기화 정지 위치를 따른다. 현재 데스크톱은 재생 중 커서를 엔진에 전송하지 않는다. 실시간 PC 영상 스트리밍은 제공하지 않는다. 선택 위치부터 15/30/60초 구간을 H.264/AAC 미리보기로 생성해 영상·오디오를 재생할 수 있다.
- 비연결 상태에서는 연결 대기로 표시한다. 새 프로젝트로 전환되면 이전 프레임을 지운다.

## 구성

브라우저 → Tailscale Serve TCP 8766 → localhost:8767 → 읽기 전용 HTTP 어댑터 → 로컬 GUI 엔진.

HTTP 어댑터는 화면·상태·프레임·미리보기 상태와 생성한 MP4만 제공한다. POST /api/preview는 고정된 내보내기 경로로 15/30/60초 미리보기를 생성하며 편집/저장은 하지 않는다. 전용 요청 헤더가 필요하다. 그 외 쓰기 메서드는 405, 임의 파일·RPC 경로는 404다. MP4 Range 요청을 지원한다. 미리보기는 한 번에 하나 생성하며 최근 최대 4개만 유지한다. 미디어 파일 경로·엔진 인증 토큰은 전달하지 않는다. 프레임 요청은 현재 프로젝트와 시퀀스를 확인한다. 같은 tailnet에서 이 PC:8766에 접근 가능한 기기는 조회할 수 있다. 공개 인터넷 Funnel은 사용하지 않는다. 기존 HTTPS 443→8188 설정은 유지했다.

Windows 방화벽 규칙 추가는 권한 부족으로 적용되지 않았고 필요하지 않은 구성으로 전환했다. Tailscale HTTP Serve의 Host 제한을 피하여 IP 접속이 되도록 TCP 전달을 사용한다.

## 시작·중지

사용자 로그인 시 시작프로그램의 Lumina Mobile Monitor 바로가기로 어댑터가 숨김 실행된다. 수동 시작: tools/start-mobile-monitor.ps1. Tailscale Serve는 --bg로 유지된다.

외부 조회 중지: `tailscale serve --tcp=8766 off` (기존 443 서비스는 유지).
재연결: `tailscale serve --bg --tcp=8766 tcp://127.0.0.1:8767`.

PC 재시작 후 Tailscale이 연결돼야 하며, 절전/종료 중에는 접속할 수 없다. 휴대폰 자체에서의 최종 접속은 별도 확인이 필요하다. 데스크톱에서 실제 Tailscale IP로 HTTP 200과 이미지 반환, 390×844 모바일 화면, 읽기 전용 조회 중 PC 재생헤드·dirty 불변을 검증했다.


## 재생 사용법과 연결 진단

휴대폰 Tailscale이 같은 계정에서 연결됨이어야 한다. 2026-11-01 접속 실패는 S26 Ultra의 오프라인 상태였으며 연결을 켜고 정상 접속을 사용자가 확인했다.

휴대폰 페이지 새로고침 → 타임라인/슬라이더로 위치 선택 → 15/30/60초 선택 → 현재 위치부터 재생 준비 → 준비 완료 후 영상의 재생 버튼. 음량·정지·탐색은 휴대폰 안에서만 동작한다. PC 작업과 독립된 요청 시점의 렌더 결과이므로 편집 후에는 다시 준비한다. 준비하는 동안 PC 렌더 자원을 사용하며 복잡한 구간은 기다려야 한다. 다음 구간은 재생 완료 위치에서 다시 준비할 수 있다.

15초 실제 프로젝트 미리보기의 H.264 1920×1080 + AAC 48kHz, 브라우저 재생·탐색, PC 재생헤드/dirty 불변을 확인했다. 모바일 화면을 흉내 낸 PC 브라우저에서 재생했으며 휴대폰 실기기의 최종 영상 재생·직접 청취는 별도 확인 대상이다.


## 2026-11-01 휴대폰 컷 검수 화면으로 변경

구간 렌더 준비/영상 재생 버튼을 주 화면에서 제거했다. 전체 위치 슬라이더, 현재 중심 ±5초 정밀 슬라이더, ±1프레임/±1초, 선택 트랙의 이전/다음 경계, 클립 첫/마지막 사용 프레임으로 이동한다. 타임라인 눈금 드래그와 클립 내부 위치 터치도 지원한다. 마지막 프레임은 배타적 out에서 1프레임 전이다. 기준 트랙이 빈 위치면 클립 없음으로 표시한다.

현재 위치에 걸린 V/A 클립의 이름·시간·활성/숨김/음소거를 표시하고 Chat 전달 텍스트에 프로젝트·시퀀스 ID·타임코드·프레임·ticks·클립 ID·소스 시작·속도를 넣는다. HTTP 환경의 클립보드 권한이 없으면 텍스트 선택 복사로 대체한다.

빠른 이동은 100ms 동안 모아 요청하고, 한 프레임만 조회한다. 이미 처리 중인 요청의 결과가 이전 위치이면 화면에 적용하지 않고 마지막 선택 위치를 다시 조회한다. 기다리는 동안 이전 이미지는 흐리게 표시하며 표시 프레임 번호와 선택 번호를 구별한다. 영상 구간 렌더는 요청하지 않지만 한 장의 합성 프레임 조회 시간은 장면 복잡도에 따라 걸릴 수 있다. PC 편집/재생헤드는 변경하지 않는다. 기존 미리보기 API는 남아 있으나 새 UI는 호출하지 않는다.
