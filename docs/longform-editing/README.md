# Caddynote 롱폼 자동화

편집을 계획하기 전에 [Codex / Claude 공용 문법](../editing-grammar/README.md), [공통 컷 문법](../editing-grammar/common-cuts.md), [롱폼 편집 문법](../editing-grammar/longform.md)을 읽는다.

롱폼 자막을 생성하거나 분할할 때 [자막 분할 기준](caption-segmentation.md)을 추가로 읽는다. 쇼츠 분할기 설정을 그대로 적용하지 않는다. Phrase Studio v1은 구현되어 있지만 [호시노 자막 감사](hoshino-audit/README.md)에서 의미 경계 문제가 확인되었고 실제 폰트 폭 기반 분할은 아직 구현하지 않았다.

[네 편의 벤치마크 근거·개선점](reference-benchmark/README.md)와 [Lumina 실행·검수](../editing-grammar/lumina-workflow.md)를 함께 사용한다. 호시노의 완성 편집 기준은 **인계 파일의 시퀀스 09**다. 이전 SRT 감사와 완성 타임라인의 버전을 혼동하지 않는다.

기준 자료: 타카나시 호시노, 이시고리 류, 덴지, 레제의 로컬 SRT와 Premiere 프로젝트. 프로젝트는 읽기만 했다.
