# 소스 검수

`창 > 소스 검수`에서 활성 소스를 다룬다. 기존 Lumina `~/.lumina/source.db`를 사용하며 프로젝트 타임라인은 변경하지 않는다.

## 화면과 경계

- 왼쪽은 선택 컷의 시작 프레임으로 고정, 오른쪽은 끝 경계 직전의 마지막 유효 프레임이다. 양쪽을 같은 컷의 화면으로 맞추며 검수한다.
- 시작/끝 선택 스위치는 없다. 플레이바와 1프레임 버튼은 선택 컷 끝 경계를 바꾸고 다음 컷 시작도 함께 이동시킨다.
- 마지막 컷 끝은 소스 끝으로 고정하므로 이동 조작을 막는다. 두 컷을 최소 한 프레임씩 남기는 범위로 제한한다.
- 선택 컷 재생은 오른쪽에서 시작부터 끝까지 재생한다. 왼쪽 시작은 유지되며 재생 자체는 저장하지 않는다.
- 컷 이동은 이전/다음, 컷 선택, 목록 검색을 사용한다. 분할·병합과 추가 분석은 분석·관리에서 연다.

## 통합 정보와 enum

정보·대사·태그를 한 패널에 배치한다. 경계/근거 탭, 수동 저장/검수 완료/DB 반영 하단 버튼은 없다.
대사는 한 줄씩 화자와 내용을 편집하고, 시간은 필요할 때 펼친다. 원본 URL·에피소드·메모는 공통 정보에 있다.

IP는 `LUMINA_ENTITY_CATALOG` 또는 `D:/Dev/shared/entity_catalog.db`의 기존 공유 카탈로그에서 검색·선택한다.
등장인물과 화자는 해당 IP의 인물 enum을 사용한다. 화자는 이 컷에 이미 등록된 등장인물·기존 화자도 별도 그룹에서 선택할 수 있어 미등록 IP에서도 막히지 않는다. 화자는 화면에 등장했다는 이유만으로 자동 지정하지 않는다.
소스 종류와 샷도 정의된 enum을 사용한다. 카탈로그에 없는 기존 값은 ‘기존 값’으로 보존하고 새 자유 입력은 허용하지 않는다.
IP를 바꾸면 이전 IP의 등장인물·화자 선택을 비운다. DB 누락은 오류로 표시하며 임의 목록을 만들지 않는다.

## 자동 저장

- 입력·경계 이동 후 약 350ms 동안 추가 입력이 없으면 검수 초안과 검색 DB를 하나의 SQLite 트랜잭션으로 저장한다.
- 연속 입력은 합쳐 보내고 요청은 순서대로 처리한다. 저장 응답이 뒤늦게 와도 새 입력을 덮지 않는다.
- 소스 전환 시 대기 중인 수정은 원래 media_id에 저장한다. 한국어 조합 중에는 중간 문자열을 전송하지 않는다.
- 저장 상태/실패를 상단에 표시한다. 실패하면 입력과 대기열을 유지하며 재시도할 수 있다. 충돌을 임의로 덮어쓰지 않는다.
- revision, 기존 DB fingerprint, 소스 파일 변경 여부를 검사한다. 여러 변경 중 하나가 실패하면 전부 롤백한다.
- 바꾼 필드는 human 또는 agent 출처로 기록하고, 손대지 않은 분석 값의 제안/승인 상태는 유지한다. 모든 컷을 검수 완료로 만들지 않는다.
- 이전 검색 정보는 rejected 이력으로 보존한다. 이 화면의 되돌리기는 복원 내용까지 검색 DB에 자동 반영한다.

## 기존 분석과 ingest

기존 cut/fact/job 및 검수 초안을 먼저 읽는다. 1차 분석된 소스는 재분석 없이 바로 표시한다.
미분석 소스는 ingest 또는 컷 검출, 일부 분석된 소스는 빠진 분석만 실행한다.
장면/태그 분석은 누락 컷만 처리하며 완료된 분석을 모델 버전만으로 재실행하지 않는다.
장면 설명은 Claude CLI, 태그·ASR은 로컬 analyzers를 사용한다. 실패한 런타임은 오류로 표시한다.

## API와 검증

`source_review.choices(query, work)`는 IP 검색 결과, 해당 인물, 소스 종류와 샷 선택값을 반환한다.
`source_review.save(media_id, revision, changes)`는 변경과 검색 반영을 원자적으로 수행한다.
기존 draft-only update/preview/publish/import_srt API는 호환성을 위해 유지한다. GUI의 실시간 저장은 save API를 사용한다.
`LUMINA_SOURCE_DB`로 격리 테스트 DB를 지정한다. media_id는 프로젝트 미디어 ID다.

`engine/tests/sourcedb/test_review.py`: 자동 반영·롤백·공유 경계·되돌리기·enum·출처 보존·충돌 검증.
`app/test/source-review.mjs`: 임시 카탈로그/소스 DB에서 실제 프레임, 자동 저장 및 검색 fact, 마지막 경계 제한, 입력 실패 재시도, 저장 중 입력, 소스 전환, 패널 배치 검증.
