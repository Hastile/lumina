- 개선: 같은 분위기를 주는 도입을 관성적으로 길게 유지하지 않는다. 설명의 궁금증을 실제로 만드는지 확인한다.

### R2. 01:05.44~01:09.03 / 01:22.17~01:24.54: 색채 의미 키워드 누적 (T)

- 관찰: `이중성 → 모순 → 우울함`, `편안함 → 안정 → 회복`이 시간차로 추가된다.
- 유지: 같은 이미지 위에 의미를 누적하고 최신 항목에 주의를 준다.
- 개선: 색의 의미를 보편적인 사실로 단정하지 않고 해당 작품의 맥락·반례를 고려한다. 모든 항목마다 같은 강도의 타격음은 피로도 검수 대상으로 둔다.

### R3. 01:28.21~01:30.92 / 01:42.14~01:45.56: 비교와 출처 (T/S)

- 관찰: 조커·초호기·피콜로 비교 라벨, 후지모토/편집장 인터뷰 인용이 있다. 소스 프레임에서 피콜로, 별도 시점에서 Reseda 식물 이미지를 확인했다.
- 유지: 비교 대상을 화면에 남기고 인용의 출처를 명시한다.
- 개선: 긴 인터뷰를 읽기 어려운 크기로 한꺼번에 띄우기보다 핵심 발언과 출처를 분리한다. 미디어 추출만으로 인용 내용의 사실성을 검증했다고 주장하지 않는다.

### R4. 07:36.54~07:45.30: STP 설명의 시각적 단계 (T)

- 관찰: S/T/P가 유지되고 `체인소맨 보는 사람` → `마키마 말고 다른 여캐가 보고 싶은 사람` → `그럼 폭탄 여자 맛 볼래?`가 추가된다.
- 유지: 개념을 먼저 큰 글자로 끝내지 않고 구체적인 사례를 단계적으로 매칭한다.
- 개선: 약어를 모르는 사람도 따라오도록 한국어 역할을 짧게 붙인다. 마지막 항목 추가 후 전체 관계를 읽을 시간을 확인한다. 이 시점의 실제 소스 샘플은 누락되어 최종 배치의 시각적 품질은 미확인이다.

|---|---|---|---|
| 실제 소품·문화 자료 삽입 | 설명의 구체성 | 대상 부위 확대, 주장의 근거/비유 구분 | 쇼츠·롱폼 |
| 인물/키워드 순차 추가 | 비교와 기억 유지 | 같은 비교 축, 마지막 상태 읽기 시간 | 쇼츠·롱폼 |
| 실제 원작 행동·대사 삽입 | 주장 입증과 캐릭터 경험 | 사건 정확성, 공개 시점, 음성 충돌 검수 | 쇼츠·롱폼 |
