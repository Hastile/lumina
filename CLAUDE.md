# Lumina — shared editing instructions

Read `AGENTS.md` for repository instructions.

For Caddynote editing, start at `docs/editing-grammar/README.md`. Codex and Claude use the same shared documents, reference evidence, cut-planning table, and Lumina MCP verification workflow. Do not maintain a divergent model-specific copy of the grammar.

Common cut grammar applies to Shorts and long-form. For Shorts, start with `docs/shorts-editing/CARD.md` and open `docs/shorts-editing/README.md` only for what the card does not cover; or `docs/longform-editing/README.md` for long-form. Use the Hoshino handoff project's `시퀀스 09` as its completed reference. Edit projects through Lumina MCP, never by rewriting `.lumina` files with side scripts.

The user's Shorts requests are terse ("<쇼츠> 세팅해줘", a pasted file path, "마무리"). Read them by the table at the top of `docs/shorts-editing/CARD.md` and carry out the whole flow it names; do not ask the user to spell out steps.
