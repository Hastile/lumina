이번 보강: 커뮤니티 원문·반응 범위, 확정 목록 인원·순서, 그대로 TTS 원문 대조, 쇼츠 자막 검수, TMI 한 자막/작품명 위치, SFX 사전 계획·꼬리·무음 구간, 지정 파일 이동/등록 미디어만 relink, 타임라인 전후 비교.

이번 작업은 지침 보정이다. Lumina 앱 재설치나 프로젝트 재저장은 필요 없고 실제 타임라인·미디어는 변경하지 않았다. Chat 업로드는 자동 동기화되지 않는다.
