## 우선순위와 근거 표시

사용자의 현재 지시 > 사용자가 확정한 취향·수정 > 이 공통 문법 > 포맷별 기본값 > 레퍼런스의 빈도 통계. 원본에서 자주 보였다는 이유로 결함을 복제하지 않는다.

- **확정:** 사용자가 직접 정한 조건. 호시노 기준은 인계 프로젝트의 `시퀀스 09`. 롱폼 자막은 Pretendard Medium 60, 자간 -20, 기본 박스 폭 1440, 필요하면 좌우 확장.
- **관찰:** 파일·타임라인·이미지에서 확인한 사실. 시퀀스명과 시각을 붙인다. 트랙의 클립 수와 최종 화면 컷 수를 혼동하지 않는다.
- **해석:** 편집이 해결하려는 문제를 설명한 추론. 의도라고 단정하지 않는다.
- **제안:** 더 좋은 전달을 위한 변경안. 실제 편집과 검수에서 검증한다.

충돌이 있으면 관찰된 옛 관행보다 사용자의 최신 기준을 따른다. 동일 규칙을 Codex용/Claude용으로 따로 복사하지 않는다. 새 수정은 원칙과 사례를 함께 이 폴더에 갱신한다.

## 완료 조건

중복 장면은 매우 신중하게 재활용한다. 초안에서도 빈 구간을 같은 샷으로 때우지 않는다. 재사용의 이유와 최초 사용 대비 새 역할을 확인하고 [공통 컷 문법의 중복 검수](common-cuts.md)를 적용한다.

문서에 맞게 도구를 호출한 것만으로 편집 완료가 아니다. 중요한 대상을 볼 수 있고, 설명과 소스가 맞고, 필요한 읽기·이해 시간이 있으며, 프레임 경계와 소리가 자연스러운지 확인해야 한다. 이 문서의 개선안은 아직 완성 롱폼 A/B 검증을 거친 최적해가 아니다.
